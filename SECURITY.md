# Security

If you find a security problem in rdloom, please tell us privately first so we can fix it before it is public.

## How to report

1. Open [a private security report](https://github.com/DevHydeOut/rdloom/security/advisories/new) on GitHub.
2. Describe what you found, how to repeat it and which version you used.
3. Please do not post details in a public issue until we have replied and a fix is ready.

We will confirm we received your report, tell you what we plan to do, and credit you in the release notes if you wish.

## What counts

- A way to run code or read data in an app that uses rdloom components or the CLI.
- A problem in the CLI that writes files outside the project or overwrites files you did not ask it to change.
- A problem in the MCP server or the published npm packages (`rdloom`, `@rdloom/mcp`).

Bugs that are not security problems, such as a wrong label or a layout that breaks, belong in a normal [issue](https://github.com/DevHydeOut/rdloom/issues/new/choose).

## Supported versions

We fix security problems in the latest published version.
